# The Deforestation Driver and Carbon Emission (DeDuCE) Model

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.13624636.svg)](https://doi.org/10.5281/zenodo.13624636)

The DeDuCE model provides annual estimates of deforestation and associated carbon emissions attributable to the production of agricultural and forestry commodities worldwide. By integrating the best available high-resolution spatial data with comprehensive agricultural statistics, DeDuCE aims to improve the transparency, scope, and detail of deforestation attribution.

This repository contains the refactored and modularized codebase for the DeDuCE model, designed for improved reproducibility and maintainability. The insights and data generated by this model can be explored at [deforestationfootprint.earth](https://www.deforestationfootprint.earth).

## Model Architecture

The DeDuCE model operates as a sequential pipeline, controlled by a central configuration file (`config.yaml`). The workflow is divided into three primary modules, orchestrated by `main.py`:

1.  **Spatial Attribution (`a_spatial_attribution.py`)**:
    *   **Input**: Google Earth Engine (GEE) assets for forest cover loss, commodity maps, and other land use data.
    *   **Process**: This module uses the GEE Python API to perform a hierarchical, pixel-level attribution of tree cover loss. It overlays dozens of remote sensing datasets to determine the most likely direct driver of deforestation (e.g., expansion of soy, oil palm, pasture, or urban areas).
    *   **Output**: A series of CSV files exported to the user's Google Drive, detailing the area of deforestation attributed to specific spatial drivers for each country and year.

2.  **Gross Land Loss Analysis (`c_gross_land_loss_analysis.py`)**:
    *   **Input**: C3S land cover data and national/sub-national shapefiles.
    *   **Process**: This script calculates the gross annual loss of cropland and grassland for each specified region. This is a critical input for the statistical land-balance model.
    *   **Output**: An Excel file containing annual gross loss estimates for cropland and grassland.

3.  **Statistical Attribution (`b_statistical_attribution.py`)**:
    *   **Input**: The outputs from the spatial and gross loss modules, combined with statistical data from sources like FAOSTAT and IBGE.
    *   **Process**: This is the core data synthesis step. It performs a two-step statistical land-balance:
        1.  **Land-Use Attribution**: Attributes spatially unclassified deforestation to either cropland, pasture, or forest plantation based on their relative expansion.
        2.  **Commodity Attribution**: Further allocates cropland-driven deforestation to specific crop commodities based on their increase in harvested area.
    *   **Output**: The final, comprehensive dataset containing annual deforestation and carbon emission footprints for over 9,300 unique country-commodity pairs.

## Reproducing the Results: A Step-by-Step Guide

Follow these steps to set up the environment and run the complete DeDuCE pipeline.

### Step 1: Prerequisites

Before you begin, ensure you have the following:
*   **Git**: To clone the repository.
*   **Python**: Version 3.8 or higher.
*   **Google Earth Engine Account**: You must have a registered GEE account. If you don't, you can sign up at [earthengine.google.com](https://earthengine.google.com/signup/).

### Step 2: Setup and Installation

1.  **Clone the Repository**:
    ```bash
    git clone FINAL PATH TBD
    cd DeDuCE
    ```

2.  **Create a Virtual Environment** (Recommended):
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

3.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Authenticate Google Earth Engine**:
    Run the following command and follow the on-screen instructions to link your GEE account.
    ```bash
    earthengine authenticate
    ```

### Step 3: Data and Configuration

1.  **Download Input Data**:
    The model requires several large input datasets that are not included in this repository. You must download them and place them in the correct directory structure. 
    *   **Statistical Data**: Download the latest datasets from FAOSTAT, IBGE, etc.
    *   **Geospatial Data**: Download the required shapefiles (e.g., GADM).
    *   **Supplementary Data**: The `DeDuCE-Lookup.xlsx` file and other lookup tables are available on the project's Zenodo page.

2.  **Configure the Model**:
    This is the most critical step for reproducibility.
    *   Make a copy of the configuration template:
        ```bash
        cp config.template.yaml config.yaml
        ```
    *   Open `config.yaml` in a text editor.
    *   **Update the `base_dir` path** to the absolute path where you have stored your input data and where you want the outputs to be saved. All other paths in the config file are relative to this `base_dir`.
    *   Review other paths and parameters to ensure they match your local setup.

### Step 4: Running the Analysis

The model can be run from the command line using `main.py`.

1.  **Run the Full Pipeline** (Recommended):
    This command executes all three modules in the correct sequence.
    ```bash
    python main.py --run_all
    ```    *Note: The spatial attribution step will launch tasks in your Google Earth Engine account. You must wait for these tasks to complete and then download the resulting CSV files from your Google Drive to the directory specified in `paths.outputs.gee_exports_dir` before the statistical attribution step can succeed.*

2.  **Run Individual Steps**:
    You can also run each module independently. This is useful for debugging or if you only need to update a specific part of the analysis.

    *   **Run Spatial Attribution only**:
        ```bash
        python main.py --run_spatial
        ```
    *   **Run Gross Land Loss only**:
        ```bash
        python main.py --run_gross_loss
        ```
    *   **Run Statistical Attribution only** (Requires outputs from the other two steps):
        ```bash
        python main.py --run_statistical
        ```

### Step 5: Accessing the Results

The model generates several outputs, all located in the directories specified in your `config.yaml`:

1.  **Spatial Attribution Outputs**:
    *   **Location**: Your Google Drive, inside a folder named `DeDuCE_vX` (the version depends on your config).
    *   **Content**: A series of CSV files, one for each analysis type (Classification, AGB, BGB, etc.) per country. These must be downloaded to your local `gee_exports_dir` to be used by the statistical model.

2.  **Gross Land Loss Outputs**:
    *   **Location**: The directory specified by `paths.outputs.gross_loss_output_dir`.
    *   **Content**: An Excel file (`DeDuCE_Gross_Cropland_Grassland_Changes_...xlsx`) with separate sheets for `crop_loss` and `grass_loss`.

3.  **Final DeDuCE Results**:
    *   **Location**: The directory specified by `paths.outputs.final_results_dir`.
    *   **Content**: The primary output is a comprehensive Excel file named `DeDuCE_Deforestation_attribution_vX.X.X (YEAR-RANGE).xlsx`. This file contains the final, detailed deforestation and carbon footprints, including:
        *   Unamortized and amortized deforestation (ha).
        *   Unamortized and amortized carbon emissions (MtCO2), both with and without peatland drainage.
        *   A Quality Index (QI) for each estimate.
    *   Aggregated summary files for countries and commodities are also generated in this directory.
